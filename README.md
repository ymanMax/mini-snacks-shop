# 零食商城购物微信小程序
功能完善的零食购物微信小程序，提供商品展示、分类浏览、购物车、订单管理等功能，让用户轻松选购心仪零食。

## 功能特性

### 商品展示
- **首页轮播图**：展示热门商品和促销活动
- **商品推荐**：根据用户喜好推荐相关商品
- **分类浏览**：按商品分类进行浏览，支持多级分类
- **商品搜索**：支持根据关键词搜索商品

### 购物车功能
- **添加商品**：支持将商品添加到购物车
- **购物车管理**：支持修改商品数量、删除商品
- **全选/单选**：支持全选或单选购物车中的商品
- **价格计算**：自动计算购物车中商品的总价
- **本地缓存**：购物车数据保存在本地缓存中，刷新页面不会丢失

### 订单管理
- **创建订单**：支持将购物车中的商品生成订单
- **订单列表**：支持查看所有订单，包括待付款、待发货、待收货、已完成等状态
- **订单详情**：支持查看订单的详细信息，包括商品列表、价格、地址等
- **订单分页**：支持分页显示订单列表

### 地址管理
- **地址列表**：支持查看所有收货地址
- **添加地址**：支持添加新的收货地址
- **编辑地址**：支持修改已有的收货地址
- **删除地址**：支持删除不需要的收货地址
- **默认地址**：支持设置默认收货地址

### 个人中心
- **用户信息**：支持查看和修改用户信息
- **订单管理**：支持查看和管理用户的所有订单
- **地址管理**：支持查看和管理用户的收货地址
- **收藏夹**：支持查看和管理用户收藏的商品
- **浏览历史**：支持查看用户的浏览历史

## 技术栈

- **开发框架**：微信小程序原生框架
- **数据请求**：封装了统一的API请求函数，支持Promise
- **状态管理**：使用微信小程序的globalData进行全局状态管理
- **本地存储**：使用wx.setStorage和wx.getStorage进行本地数据存储
- **UI设计**：使用微信小程序原生组件进行UI设计，风格简洁美观
- **工具函数**：封装了常用的工具函数，如日期处理、数据格式化等

## 使用方法

### 1. 环境准备

- 下载并安装微信开发者工具
- 注册微信小程序账号（可选，用于发布）

### 2. 项目运行

- 克隆或下载本项目代码
- 打开微信开发者工具，导入本项目代码
- 点击“编译”按钮，即可运行本项目

### 3. 项目配置

- **API接口配置**：在`/utils/api.js`文件中配置API请求路径
- **全局样式配置**：在`/app.wxss`文件中配置全局样式
- **页面配置**：在各页面的`json`文件中配置页面样式和功能

## 注意事项

- 本项目使用真实的API接口，需要确保网络连接正常
- 项目中使用了本地缓存，需要注意数据的一致性
- 项目中包含多个页面和组件，需要根据实际需求进行使用和配置
